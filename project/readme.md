## King's Landing
Nguyen Ba Viet Hoang

### main_game.py

Contains the main game program, menu and game loop. It creates the player, rooms and items and handles user input.

### player.py

Contains the Player class.

The Player has:
- name
- age
- items
- location

The Player can:
- move to another room
- collect an item
- clear the inventory

### room.py

Contains the Room class.

A Room has:
- name
- an optional item

### item.py

Contains the Item class.

An Item has:
- name
- weight

## Game

The game is set in King's Landing.

The player can:
- view their location
- move between rooms
- collect items
- view their inventory
- clear their inventory
- use fictional commands
- quit the game
